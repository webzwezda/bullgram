# Платформенный пул прокси: +200 слотов и админ-индикатор

Дата: 2026-11-08. Слово владельца: «Поднимай 200 платформенных прокси. и
админу с role admin сделай в интерфейсе указание что поднято 200
платформенных прокси и сколько из них используется».

## План и исполнение

- [x] Стокинг: строки mp_66..mp_265 (200 шт) в `proxies`: host
      193.23.197.169, порты 21146-21345 (21080+seq), случайные пароли
      (генерация и вставка на srv, креды не покидали сервер), owner NULL,
      provision_source='manual_admin', inventory_group='self_use'.
      Формулы сервиса: port=21080+seq, ipv6=префикс+hex(0x1000+seq),
      state.sequence продолжён с 65 → 265.
- [x] Reconcile (`bullgram-managed-proxies-reconcile`): restored=true,
      dbCount=218, подняты 200 портов + 200 IPv6 (::1042..::1109),
      контейнер пересоздан (новые IPv6 кэшируются при старте — рестарт
      обязателен и выполнен самим reconcile).
- [x] Верификация: 218 слушателей; полные SOCKS5-хендшейки через mp_66 /
      mp_150 / mp_265 ИЗНУТРИ и mp_66 СНАРУЖИ (Mac) → каждый вернул свой
      IPv6 (::1042/::1096/::1109 = 0x1000+seq). err.jsonl 0.
- [x] Бэкенд: GET /api/userbot/proxy-pool/stats (только role=admin):
      total (все mp_*), used (привязаны к юзерботам), free (owner NULL),
      reserved (занят владельцем, не привязан). Тесты 3/1, gate-01 — 34
      сьюта.
- [x] Фронт: карточка «Платформенный пул прокси» на /userbot/proxies —
      только для role=admin, числа живые. build + no-undef + design PASS.
- [x] Доки: proxies.md/operations.md — числа пула обновлены.

## Решения и заметки

- Флаг `USERBOT_AUTO_ALLOCATE_PROXY_ENABLED` остаётся **off** — включение
  после слова владельца (тариф-правило: слот любому или только Pro).
- Ёмкость: 218 слушателей ≈ 10MB RSS (масштаб бенча 2000 ≈ 93MB), ulimit
  65535; глобальный кап MAX_MANAGED_PROXIES_GLOBAL=512 — следующее
  масштабирование за 300 слотов потребует поднять константу.
- Reconcile прислал self-heal алерт в TG (ожидаемо: restored=true — это
  штатное событие массового подъёма, не инцидент).
