## 1. Мини-волна: mono-шрифт и preload на site-v2 — ЗАВЕРШЕНО (153ee1d, деплой 2026-09-16)
**Решение.** site-v2 использует `font-mono` в 5 местах, и все — платёжные (memo, адрес кошелька, секрет счёта). Токен `--font-mono` уже отдаёт стек JetBrains Mono, но шрифт на сайте не подключён → рендер по локально установленному или ui-monospace. Решение то же, что в admin (волна 6b): копия двух woff2 в `public/fonts/` + алиасные @font-face с `/` (base сайта корневой) + preload Manrope ×2 в index.html (CLS на холодной загрузке).
**Приёмка:** билд зелёный; ratchet поймал +2 font-family (литеральные имена в @font-face — var() запрещён спекой) → осознанный baseline; на проде JBM @font-face зарегистрированы, woff2 200, preload ×2 в HTML. JBM не preloadится сознательно — нужен только на платёжных экранах (~52 КБ на остальных страницах лишние).

## 2. access_requests admin-поверхность — ОТСРОЖЕНО (триггер не сработал), защита проверена
**Факты (2026-09-16):** заявок 0; RLS включена, единственная политика `access_requests_service_role_all` (ALL только для service_role) — аноним/тенанты ПИИ не видят, запись через бэкенд с service key. Риск закрыт на уровне базы.
**Решение, когда придёт первая заявка:** НЕ мульти-тенантная страница. Это лиды платформы, не тенантные данные → read-only страница `/app/access-requests`, видимая только платформенному владельцу (gate по email владельца в AuthGate/профиле), кнопка «обработано». Час работы.
**Кто:** оркестратор по команде владельца.

## 3. border.strong и WCAG 1.4.11 — ЗАКРЫТО АНАЛИЗОМ (значение не меняем)
**Решение.** 1.4.11 требует 3:1 для границы только когда она — единственный визуальный индикатор контрола. В нашем ките контролы залиты (input `bg-slate-50`, кнопки filled) и несут focus `ring-3` — граница никогда не единственный индикатор. FAIL kit-валидатора консервативнее WCAG; он уже толерируется гейтом по точной метке. Менять slate-300 глобально = видимая дельта против де-факто.
**Действие:** абзац-резолюция в design/README.md (сделано при создании бэклога). Пересматривать, только если появятся бордер-единственные контролы без заливки.

## 4. Легаси ~5300 raw-находок → семантика — СТРАТЕГИЯ ОТСРОЧКИ
**Решение.** Big-bang не делаем. Ключевое: тюнинг значений уже работает через примитивы (slate-* алиасятся на DTCG с волны 3), семантика добавляет только интент. Codemod `text-slate-500 → text-ink-muted` механически возможен с нулевой дельтой (значения равны) — волнами с пиксельной проверкой, как волна 3; триггер — крупный редизайн/тюнинг темы.
**Правило сейчас:** каждое касание страницы — переводим затронутые классы на семантику + `--update-baseline`. Новые экраны — сразу на семантике (правило DESIGN.md).
