## 1. minio (9002/9003)

**Данные**: контейнер 2026-06-08, bind-mount `/home/n8nuser/minio-data` (55MB),
бакеты `wiki-anna` и `wiki-sync` (последняя запись 2026-11-04) — **данные Anna,
wiki-синк потребителя** (root user `wiki-sync-15b37e50`). Supabase storage
`storage.objects` = 0 строк — minio к Supabase не относится. nginx minio НЕ
проксирует (`MINIO_SERVER_URL=https://prsng.ru` — аспирационный, путей нет).
Журнал запросов пуст, активность 4 ноября — потребитель ходит напрямую на
9002 (голый HTTP — креды нешифрованные, риск зафиксирован владельцу).

**Вердикт**: НЕ удалять, НЕ останавливать. 9002 остаётся наружу (живой
консюмер Anna). 9003 (консоль с браузерным логином) — rebind на 127.0.0.1
пересозданием контейнера (ufw бесполезен: docker-порт идёт мимо INPUT;
DOCKER-USER неперсистентен при ребуте). Образ пиннить текущим image-ID
(плавающий tag = внезапный апгрейд). Откат: прежний `docker run` из инспекта.

**Открыто на владельца**: креды wiki-синка ходят plaintext-ом по интернету
на 9002; лечение — TLS на minio или tailnet-путь у консюмера.

## 2. ufw 3000

**Доказано**: правило «3000 ALLOW» [4] — тень: catch-all `1024:65535 ALLOW`
стоит НАД ним [3] (первое совпадение выигрывает; сужение/удаление точечного
правила — плацебо). :3000 — порт pm2-процесса → INPUT применим. Консюмеры:
nginx — loopback; n8n — 272 вызова только на bullgram.xyz:443 (grep его
sqlite); established на :3000 — ноль; Kuma — домены/443.

**Вердикт**: ordered inserts ВЕРХ цепочки user-rules (до catch-all):
allow 172.16.0.0/12 (docker-мосты) → allow 100.64.0.0/10 + fd7a:115c:a1e0::/48
(tailnet) → deny :3000. Мёртвые правила «3000 ALLOW» (v4+v6) удалить.
Независимая проверка: пробы с Mac (3000 закрыт, 443/health жив), ufw-лог
видит заблокированные попытки (сам becomes сенсором). Откат: `ufw delete` по
номерам. 3002 (bullrun-api, чужой проект) не трогаем — отмечено владельцу.

## 3. ANON_KEY (PGRST301)

**Root-cause доказан HMAC'ом**: anon-ключ (демо-строка `S88_k_U0Nl7…`,
payload {role:anon,iss:supabase}) не подписан НИ живым JWT_SECRET (45 симв.),
НИ стандартным demo-секретом — артефакт предыдущей итерации стека. Он один и
тот же во всех местах: docker .env → kong-консюмер `$SUPABASE_ANON_KEY` →
8 файлов фронтов (6× config.js + 2× api/config.js) → MCP-конфиг Mac (--anon-key).
Прод работает потому, что kong key-auth сверяет apikey со СТРОКОЙ консюмера
(совпадает), а rest верифицирует только USER-JWT (живой секрет).

**Вердикт**: миграция на минтованный HS256 `{"role":"anon","iss":"supabase"}`
живым секретом, в 4 фазы с dual-key на kong (без даунтайма):
1) kong.yml anon-консюмер: env-ключ (старый) + статический НОВЫЙ → recreate
   kong; 2) репо: 8 литералов → новый → push+deploy (6 аппов пересборка);
3) docker .env ANON_KEY → новый + recreate затронутых сервисов compose;
4) kong.yml: убрать статический старый → recreate → проверка: старый 401,
   новый 200, PGRST301 на anon-as-Bearer исчез. MCP-конфиг Mac обновить,
   если там старый anon. Откат каждой фазы: бэкап файла + recreate kong.

## 4. BACKLOG §32-33

**Числа**: пользователей 5 (за 30 дней +3), tg_accounts 11, proxies 18 (все
mp_ managed), свободных слотов owner_id NULL = **0** — пул исчерпан.

- **§32 (авто-прокси)**: вердикт — СТРОИМ, но JIT при создании юзербот-аккаунта
  (не при регистрации: GoTrue напрямую минует backend; «1 аккаунт = 1 прокси»
  по правилам AGENTS). Флаг `USERBOT_AUTO_ALLOCATE_PROXY_ENABLED` default
  false (пул пуст — включать после пополнения), исчерпание → TG-алерт с dedup.
  Атомарный claim условным UPDATE (... where owner_id is null RETURNING).
- **§33 (авто-возврат лотов)**: события карантинов редки (2 за инцидент
  2026-11-07), но ручное восстановление = сессия агента с контекстом. СТРОИМ
  симметричный двухстрайк: колонка `tg_accounts.healthy_streak`; только
  infra-карантины (dead_proxy/error) восстанавливаются после 2 подряд
  online; restricted/frozen/expired → sentinel −1 (никогда); карантинные
  лоты дочекериваются 14 дней (по shop_items.updated_at); восстановление =
  published/public + is_working=true (как в proxies.md §6) + TG-алерт.
  Миграция до деплоя.
