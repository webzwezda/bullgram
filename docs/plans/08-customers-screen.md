## Раунд 3 — замечания Ильи по живой работе с экраном (коммиты 744054c, 30e5bef, de4d990, f046871)

1. **«Конвертик» вёл на пустую страницу.** Два слоя проблемы:
   - `openUserbotCenterHandoff` делал `navigate('/app/userbots...')` при `basename="/app"`
     у BrowserRouter → URL `/app/app/userbots` → нет роута → пустая страница.
     Правило: внутри роутера с basename пути БЕЗ `/app` (navigate/Link); `/app/...` — только
     для обычных `<a href>`. Починены также OpsRail и BroadcastPage (Link to="/app/...").
   - Handoff падал на вкладку «Профиль» юзербота, а композера ЛС в UI вообще не было.
     Добавлен блок «Написать в ЛС клиенту» (TG ID + общий чат + текст + «Отправить ЛС»)
     на вкладку групп; handoff открывает сразу её и префиллит поля (TG ID клиента + chat).
2. **Колонка «Приватка»** в таблице открытых групп: бейдж «Активна»/«Истекла» из crmMap.
3. **Вкладки бота:** 9 → 6: убраны Сгорели-но-сидят / Оплаченные / Удален админом / Не смог войти;
   вкладки всегда видимы (не прячутся при смене сегмента), со счётчиками.
4. **«Не смогли оплатить» удалена** — дубль «Создали счет» (оба = создан счет без оплаты).
   Старые ссылки ?tab=abandoned маппятся на invoice-created.
5. **Bulk-кнопки** (+5 дней / +30 дней / Кикнуть хвост / → Рассылка) удалены по просьбе Ильи.
6. **Воронка:** метки «Воронка клиентов»/«Деньги» убраны; остались 2 некликабельные карточки
   (Активный доступ / Доступ закончился).
7. **Деньги:** одна карточка «Выручка TON» + селектор периода 7 дней / 30 дней / За всё время.
   Бэкенд: /api/analytics?period=7|30|all → revenuePeriodTON (аналитикс-роут).

## Уроки

1. **Legacy `.grid` из app.css** (unlayered `grid-template-columns: repeat(auto-fit, minmax(260px,1fr))`)
   перебивает Tailwind-утилиты колонок на любом элементе с классом `grid`. Рабочий приём —
   `[display:grid]` вместо `grid` (так уже сделано в OfficialBotsSection). Диагностика: сетка
   рендерит не те колонки, что в классах, причём число колонок «плывёт» с шириной контейнера.
2. **Проверка свежести бандла:** при проверке деплоя в браузере страница может отдать кешированный
   index.html со старым чанком. Надёжный обход: `fetch('/app/', {cache:'reload'})` + переход по
   URL с уникальным query-параметром; сверять хеш `script[src*=index-]`.
3. При проверке «странного» рендера сначала убедиться, что виден свежий бандл, а не искать баг в коде.
