# Правило проверки фронтовых изменений

## Урок (2026-09-12, субагент-критик поднял dev-сервер)

Субагент `design-critic` для проверки главной страницы поднял локальный dev-сервер и снимал скриншоты через headless Chrome. Пользователь повторил правило жёстче: **все тесты — только через его настоящий Chrome, только боевая версия после деплоя**.

## Правило

- Не запускать `site-v2` / `admin-v2` локально для просмотра (никаких `npm run dev` + браузера), в том числе из субагентов. Субагентам это прямо запрещать в промпте.
- Проверка фронтовых изменений — через `npm run build` (сборка должна быть зелёной).
- Живой взгляд на результат — только на проде после деплоя (push → GitHub Actions → `scripts/deploy-pull.sh`): `https://bullgram.xyz`, админка `/app`.
- Тесты прода гоняем через настоящий Chrome пользователя: Playwright MCP в режиме extension (`playwright` в `.mcp.json`, `@playwright/mcp --extension`) + расширение «Playwright Extension» из Chrome Web Store. Пользователь жмёт Connect в расширении — агент управляет его реальной вкладкой с залогиненными сессиями.
- Headless Chrome / dev-серверы — только если пользователь сам попросит, с явным указанием причины.
