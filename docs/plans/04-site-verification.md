# Правило проверки фронтовых изменений

## Урок (2026-08-25, работа над главной страницей)

Во время редизайна главной я поднял локальный dev-сервер (`npm run dev`) и открыл сайт в браузере для визуальной проверки. Пользователь явно попросил: **не открывать сайт локально**.

## Правило

- Не запускать `site-v2` / `admin-v2` локально для просмотра (никаких `npm run dev` + браузера).
- Проверка фронтовых изменений — через `npm run build` (сборка должна быть зелёной).
- Живой взгляд на результат — только на проде после деплоя (push → GitHub Actions → `scripts/deploy-pull.sh`).
- Исключение — только если пользователь сам попросит поднять локальный сервер.
